problem - Long data retrival time from 3 unconnected sources like Salesforce, Spreadsheets and Documents. 

Solution- Unified orchestrator that will talk to these sources and fetch information, reducing information retrival time to under 2 mins

technologies used - 

- **Backend: Python, FastAPI**
- **Database:** PostgreSQL
- **Operator Interface:** Streamlit
- **AI:** OpenAI Responses API with custom function tools
- **Workflow:** LangGraph for bounded state and human approval
- **Local Deployment:** Docker Compose
- **Testing and CI:** pytest, GitHub Actions
